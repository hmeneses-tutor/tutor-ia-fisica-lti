• Diagnóstico: te hace preguntas para evaluar tu nivel.

Guardado automático activo

El tutor guarda automáticamente un borrador local para poder recuperar una sesión interrumpida. Si ingresas desde Moodle mediante LTI 1.3, la sesión también queda asociada a tu identidad de Moodle y puede recuperarse desde otro navegador mientras el almacenamiento del servidor sea persistente. “Exportar PDF” abre una vista para imprimir/guardar como PDF (por ejemplo, para subir a Moodle).
